Our project is a command-line game inventory management system that allows players to track their items within a specific game catalog created by a developer. Overall, this database will be used as a tracker and info library for both players and creators and will focus less on the gameplay mechanics of a given game. Creators design catalogs (games) and define the items within them, while players join a catalog by creating an associated inventory that can add, remove, and equip items. Items may have different types and attributes, such as rarity or category, and some items (resources) can be used by creators to signify items that may be used to craft other items. This also means that players may sort and search through the various items in a given catalog.

A database is great for this system because it provides storage and maintains relationships between creators, catalogs, players, inventories, and items. It also supports efficient searching, sorting, and updating of inventory data while having good scalability and data integrity.
